## 1. 文档目的

本任务书用于对智识云知识库（kb-backend）已接入的大模型能力进行**分批次**、**可量化**的功能验证，覆盖四类核心能力：

| # | 能力 | 对应配置 | 主要实现 |
|---|------|----------|----------|
| 1 | LLM 大模型（对话生成） | `kb.llm`（DeepSeek） | [ChatStreamService.java](file:///d:/java%20workspace/demo/src/main/java/com/zhishiyun/kb/service/ChatStreamService.java) / [DocumentAskStreamService.java](file:///d:/java%20workspace/demo/src/main/java/com/zhishiyun/kb/service/DocumentAskStreamService.java) |
| 2 | 视觉大模型（图片/扫描页理解） | `kb.vision`（DeepSeek-OCR @ SiliconFlow） | [VisionClient.java](file:///d:/java%20workspace/demo/src/main/java/com/zhishiyun/kb/client/VisionClient.java) / [IngestService.java](file:///d:/java%20workspace/demo/src/main/java/com/zhishiyun/kb/service/IngestService.java) |
| 3 | Embedding 向量化 | `kb.embedding`（豆包 doubao-embedding，2048 维） | 配置于 [application.yml](file:///d:/java%20workspace/demo/src/main/resources/application.yml) |
| 4 | 向量数据库 | `kb.milvus`（Zilliz Cloud 托管 Milvus） | 配置于 [application.yml](file:///d:/java%20workspace/demo/src/main/resources/application.yml) |

测试方式以**后端接口 + 直连模型供应商 API** 为主，管理后台操作为辅，最终以**端到端 RAG 链路回归**收口。
