# 智识云 · AI 知识库 Agent 平台 — 前端需求规格说明书

> **文档说明**  
> 本文档依据前端工程 `frontend-ai-knowledge-assistant` 现有实现反推整理，描述产品应具备的功能、交互、数据与边界。  
> 当前前端为高保真原型（Mock-first），业务数据多为本地静态数据，持久化仅使用 `localStorage`。对接后端时，应以本需求为准替换数据层与鉴权层。

> **整理日期：** 2026-07-29  
> **产品名称：** 智识云 · AI 知识库

## 2. 总体架构与信息架构

### 2.1 应用视图结构

应用不使用 URL 路由，以视图状态切换页面。视图枚举：

```
chat | search | browse | history | profile | favorites | help | stats
```

**渲染优先级：**

1. 未登录 → 登录/注册页（`AuthPage`）
2. 已打开原文文档 → 原文阅读器全屏覆盖（`DocumentReader`）
3. 按当前 `view` 渲染对应业务页
4. 默认 → 智能问答页（`ChatPage`）

### 2.2 模块地图

```
登录 / 注册 / SSO
        ↓
智能问答（主工作台）
  ├─ 知识搜索
  ├─ 探索知识库
  ├─ 我的对话（历史）
  ├─ 原文阅读器（任意入口打开）
  └─ 个人中心
       ├─ 我的收藏
       ├─ 我的对话历史
       ├─ 我的使用统计
       └─ 使用帮助 / 常见问题
```

### 2.3 跨页传参约定

| 传参 | 用途 |
|------|------|
| `chatSeed` | 从搜索/浏览/历史/收藏/统计跳回问答时，预填输入框内容；问答页以该值为 key 强制重建 |
| `activeDoc`（SourceDoc） | 打开原文阅读器：`id / title / page / knowledgeBase / excerpt` |

### 2.4 知识库范围（全局枚举）

| ID | 展示名称 | 使用场景 |
|----|----------|----------|
| `all` | 全部知识库 | 问答范围、搜索筛选 |
| `product` | 产品知识库 | 问答/搜索/浏览/个人偏好 |
| `hr` | 人事制度库 | 同上；问答默认选中 |
| `tech` | 技术文档库 | 同上 |
| `support` | 售后 FAQ | 同上 |

> 个人中心「默认知识库范围」不含「全部」，为多选 chip：产品 / 人事 / 技术 / 售后。

### 2.5 主题与本地存储

| localStorage Key | 取值 | 说明 |
|------------------|------|------|
| `zn-authed` | `'1'` / 不存在 | 登录态标记（无 Token） |
| `zn-theme-mode` | `light` / `dark` / `system` | 外观模式；`system` 跟随系统并监听 `prefers-color-scheme` |

主题通过 `document.documentElement` 的 `data-theme="light|dark"` 生效。品牌主色：信任蓝 `#2563eb`。

## 3. 功能需求详述

---

### 3.1 账号与准入（登录 / 注册）

#### 3.1.1 功能概述

未登录用户唯一入口。提供品牌展示、企业 SSO、邮箱/手机账号登录、企业邮箱注册、中英双语切换。

#### 3.1.2 页面布局

| 区域 | 内容 |
|------|------|
| 左栏品牌区 | 产品名「智识云 · AI 知识库」、副标题、slogan、神经网络视觉、知识类型浮标（文档/图片/表格/演示/企业数据） |
| 右栏表单区 | 登录/注册 Tab、表单、语言切换、版权页脚 |

#### 3.1.3 登录模式

1. **企业 SSO 登录**
   - 按钮文案：企业 SSO 登录
   - 副文案：OAuth 2.0 · Azure AD
   - 行为：点击即视为登录成功（正式实现需对接真实 OAuth）

2. **账号登录**
   - 分隔文案：或使用账号登录
   - 子 Tab：邮箱登录 / 手机号登录
   - 字段：
     - 邮箱 Tab：账号（placeholder：请输入邮箱 / 手机号）
     - 手机 Tab：手机号（placeholder：请输入手机号）
     - 密码（可显示/隐藏）
   - 选项：记住我（默认勾选）；忘记密码（入口需保留，正式实现需邮件/短信重置流）
   - 提交按钮：登录

3. **注册**
   - 提示：使用企业邮箱注册，管理员审核通过后即可登录
   - 字段：姓名、企业邮箱、设置登录密码
   - 提交按钮：注册并登录

#### 3.1.4 校验规则

| 场景 | 条件 | 错误提示（中文） |
|------|------|------------------|
| 登录 | 账号为空 | 邮箱 Tab：请输入邮箱或手机号；手机 Tab：请输入手机号 |
| 登录 | 密码为空 | 请输入密码 |
| 注册 | 姓名/账号/密码任一为空 | 请完整填写注册信息 |

> 原型未做邮箱/手机号格式、密码强度校验；正式版建议补充。

#### 3.1.5 国际化

支持「简体中文 / English」切换，表单文案、slogan、错误提示同步切换。

#### 3.1.6 登录成功 / 登出

| 动作 | 行为 |
|------|------|
| 登录成功 | 写入 `zn-authed=1`，进入智能问答页 |
| 退出登录 | 清除 `zn-authed`，关闭原文阅读器状态，回到登录页 |

#### 3.1.7 验收要点

- [ ] 未登录无法进入业务页
- [ ] SSO / 账号登录 / 注册均可进入主站（对接后端后需真实鉴权）
- [ ] 必填校验文案正确
- [ ] 中英文切换完整
- [ ] 登出后再次访问需重新登录

### 3.2 智能问答（核心）

#### 3.2.1 功能概述

主工作台：左侧会话导航 + 右侧多轮问答、来源溯源、反馈与追问。

#### 3.2.2 侧栏

| 元素 | 需求 |
|------|------|
| 品牌 | 展示「智识云」 |
| + 新对话 | 创建新会话并进入空白/欢迎态 |
| 知识搜索 | 进入知识搜索页 |
| 探索知识库 | 进入知识库浏览页 |
| 我的对话 | 进入对话历史页 |
| 搜索历史对话 | 输入框 placeholder「搜索历史对话…」，过滤侧栏会话列表 |
| 会话分组 | 按时间分组展示（如：今天 / 昨天）；每项展示标题、知识库范围、时间；支持选中高亮与更多操作入口 |
| 用户卡片 | 展示用户名（示例张明）与「设置」，点击进入个人中心 |

#### 3.2.3 顶栏

| 元素 | 需求 |
|------|------|
| 知识库范围下拉 | 默认「人事制度库」；可选：全部 / 产品 / 人事 / 技术 / 售后；切换后影响后续检索范围，并给出操作提示 |
| 分享对话 | 生成/复制分享链接 |
| 清空对话 | 清空当前会话消息（需确认更佳，原型为即时清空提示） |

#### 3.2.4 对话区 — 正常回答

用户提问示例能力：支持展示用户气泡与 AI 回答气泡。

**回答内容要求：**

- 结构化表述（段落 + 要点列表）
- 关键处标注引用序号，如 `[1][2]`
- 展示免责声明与耗时信息（示例文案：AI 可能出错，请以原文为准 · 回答耗时 2.3s）

**参考来源区：**

- 标题：参考来源（N）
- 每条来源卡片包含：
  - 文档标题 + 页码标签（如《员工手册 2026 版》· 第 23 页）
  - 知识库归属
  - 原文摘录（高亮展示）
  - 操作：「查看原文 →」→ 打开原文阅读器并定位到对应页

**回答工具栏：**

| 按钮 | 需求 |
|------|------|
| 有帮助 | 记录正向反馈 |
| 没帮助 | 打开负面反馈弹窗 |
| 评分 | 对回答打分（星级等） |
| 复制 | 复制回答文本到剪贴板 |
| 重新回答 | 基于同一问题重新生成回答 |

#### 3.2.5 对话区 — 无答案空态

当知识库中无法检索到有效答案时（原型以提问含「联系人 / hr / 人事电话 / 没找到 / 找不到」等触发），展示：

1. 主文案：抱歉，我在您有权访问的知识库中未找到相关信息。
2. 引导建议列表，例如：
   - 换个问法，例如「司龄 8 个月可以休年假吗？」
   - 切换到「全部知识库」范围
   - 联系 HR 部门
3. 业务联系人卡片：姓名、岗位、联系方式（企业微信 / 分机等）

#### 3.2.6 输入区（Composer）

| 项 | 需求 |
|----|------|
| 输入控件 | 多行文本框，placeholder「继续追问…」 |
| 预填 | 支持从其他页面带入初始问题文案 |
| 发送 | 按钮「发送」；内容为空或发送中时禁用 |
| 发送中态 | 展示加载动画，防止重复提交 |
| 操作提示条 | 分享/切换范围/反馈等操作后展示短暂 status 提示 |

#### 3.2.7 验收要点

- [ ] 可选知识库范围并影响问答上下文
- [ ] 回答含结构化内容与引用来源
- [ ] 可从来源跳转原文并定位页码
- [ ] 支持有帮助 / 没帮助 / 评分 / 复制 / 重新回答
- [ ] 空答案态文案与联系人引导完整
- [ ] 空内容不可发送；发送中有禁用态

### 3.3 负面反馈弹窗

#### 3.3.1 触发

问答工具栏点击「没帮助」。

#### 3.3.2 表单字段

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| 问题类型 | 单选 | 是 | 默认「答案不准确」 |
| 补充说明 | 多行文本 | 否 | placeholder：请描述正确的答案或遗漏的信息… |
| 我知道正确答案 | 勾选 | 否 | 勾选后展开正确答案输入框 |
| 正确答案 | 多行文本 | 条件 | placeholder：请填写你认为正确的答案… |

**问题类型枚举：**

1. 答案不准确  
2. 引用了错误的文档  
3. 没有找到应该有的知识  
4. 回答不完整  
5. 其他  

#### 3.3.3 交互

- 标题：帮助我们改进  
- 副文案：您的反馈将用于优化知识检索质量  
- 操作：取消 / 提交反馈；点击遮罩可关闭  
- 提交成功提示：感谢反馈，我们会尽快优化  
- 提交后重置表单并关闭  

#### 3.3.4 验收要点

- [ ] 五种问题类型可选
- [ ] 「我知道正确答案」联动展开输入框
- [ ] 提交成功有确认反馈，弹窗关闭

### 3.4 知识搜索

#### 3.4.1 功能概述

对企业知识做只读全文检索：关键词搜索、分类筛选、排序、结果高亮、跳转阅读或基于文档提问。

#### 3.4.2 页面元素

| 元素 | 需求 |
|------|------|
| 品牌 | 智识云 |
| 去问答 | 跳转智能问答（可携带当前搜索词作为提问种子） |
| 搜索框 | placeholder：搜索文档、制度、产品说明… |
| 筛选 Chip | 全部 / 产品 / 人事 / 技术 / 售后 |
| 排序 | 最相关（默认）/ 最新更新 / 最多浏览 |
| 结果统计 | 「找到 N 条相关知识」或「没有匹配结果」 |
| 热门搜索 | 侧边/区域展示热词，如：报销流程、年假规定、产品 A 规格、考勤制度；点击填入并检索 |
| 只读声明 | 只读浏览 · 无上传 / 删除 / 编辑入口 |

#### 3.4.3 结果卡片字段

| 字段 | 说明 |
|------|------|
| 文件类型图标 | pdf / word / excel / ppt / image |
| 标题 | 文档标题 |
| 高亮摘录 | 关键词前后文 + highlights 高亮 |
| 元信息 | 知识库 · 页数 · 更新日期 · 浏览量 |
| 操作 | 「阅读」打开原文；「基于此文提问」跳转问答并预填「基于「{标题}」继续提问：」 |

#### 3.4.4 检索逻辑（产品期望）

- 匹配范围：标题、摘录、高亮词、知识库名称等
- 分类筛选与关键词可组合
- 排序：相关度 / 更新时间 / 浏览量

#### 3.4.5 空态

文案：未找到相关内容，试试 AI 问答？  
操作：去 AI 问答（携带当前 query）

#### 3.4.6 验收要点

- [ ] 关键词 + 分类 + 排序可用
- [ ] 结果高亮正确
- [ ] 阅读 / 基于此文提问跳转正确
- [ ] 空态可一键去问答
- [ ] 无上传/编辑/删除入口

### 3.6 原文阅读器

#### 3.6.1 功能概述

以 PDF 预览风格展示文档原文，支持定位引用页、高亮段落、缩放翻页，并提供 AI 摘要 / 相关片段 / 同文档问答。

#### 3.6.2 入参模型 `SourceDoc`

| 字段 | 类型 | 说明 |
|------|------|------|
| id | string | 文档标识 |
| title | string | 文档标题 |
| page | number | 定位页码 |
| knowledgeBase | string | 所属知识库名称 |
| excerpt | string | 引用摘录 |

#### 3.6.3 顶栏

| 元素 | 需求 |
|------|------|
| 返回对话 | 关闭阅读器，回到进入前页面上下文 |
| 标题 + 知识库标签 | 展示当前文档信息 |
| 收藏 | 切换收藏态；正式版需同步到「我的收藏」 |
| 分享 | 复制分享链接 |
| 下载 | 下载当前文档 |

#### 3.6.4 阅读区

| 能力 | 需求 |
|------|------|
| 缩放 | 适合宽度 / 100% / 放大 |
| 页码 | 第 N 页 / 共 M 页（示例总页 86） |
| 翻页 | 上一页 / 下一页；边界禁用 |
| 引用高亮 | 打开时定位到来源页；命中页自动滚动到高亮段落 |

#### 3.6.5 右侧上下文面板（三 Tab）

| Tab | 内容 |
|-----|------|
| AI 摘要 | 本段/本页概述；标注「基于第 N 页 · {知识库}」 |
| 相关片段 | 同文档相关片段列表（含页码、标题、摘要）；点击可跳转对应页 |
| 同文档问答 | 说明「仅检索本文档」；输入「关于这份文档继续提问…」；提交「提问」 |

#### 3.6.6 移动端适配

- FAB：「关于本文档提问」
- 底部 Sheet：同文档问答输入区

#### 3.6.7 验收要点

### 3.11 使用帮助 / 常见问题

#### 3.11.1 快捷入口

| 追问技巧 | 补充场景与时间范围 | 静态提示卡片 |

#### 3.11.2 FAQ 内容（产品文案）

1. **如何开始提问？**  
   打开「智能问答」页，在底部输入框直接提问。也可先选择知识库范围，让回答更聚焦。

2. **答案里的来源是什么？**  
   每个回答会附带来源文档与原文摘录。点击「查看原文」可跳转到对应页并高亮关键段落。

3. **为什么有些知识搜不到？**  
   平台只会检索你有权限访问的知识库。可尝试换个问法，或切换到「全部知识库」。

4. **如何收藏常用内容？**  
   在原文阅读页可收藏文档；对优质回答也可收藏。之后在「我的收藏」里快速查阅。

5. **反馈「没帮助」会怎样？**  
   你的反馈会用于优化检索与回答质量，不会影响个人绩效，也不会公开你的身份信息。

## 4. 非功能需求

### 4.1 体验与可用性

- 全屏单页应用布局，侧栏 + 主内容清晰分区
- 关键操作有即时反馈（Toast / status 提示条）
- 空态、加载态、禁用态齐全
- 支持浅色 / 深色 / 跟随系统
- 原文阅读器需兼顾桌面与移动端提问入口

### 4.2 安全与合规（产品侧文案已体现）

- 登录页版权区强调：安全合规 · TLS 加密
- 回答免责：AI 可能出错，请以原文为准
- 仅检索用户有权访问的知识库（权限由后端控制）
- 反馈匿名性承诺：不公开身份、不影响绩效
- 用户侧无知识上传/删除/编辑与权限配置入口（管理能力另系统）

### 4.3 性能期望（对接后端后）

- 问答发送有明确等待态；建议支持流式输出（原型为固定延迟 Mock）
- 搜索、历史过滤应本地或服务端即时响应
- 原文定位与高亮滚动应在打开后自动完成

### 4.4 可访问性（已部分实现）

- 关键控件具备 `aria-label` / `role`（如下拉 listbox、弹窗 dialog、status live region）
- 建议正式版补齐键盘导航与焦点陷阱（尤其反馈弹窗）

## 6. 关键用户流程

### 6.1 登录进入问答

未登录 → 账号/SSO/注册 → 写入登录态 → 智能问答页。

### 6.2 问答并溯源

选知识库 → 提问 → 查看回答与来源 → 查看原文（定位+高亮）→ 返回对话继续追问。

### 6.3 搜索转问答

知识搜索 → 筛选排序 → 基于此文提问 → 问答页预填文档上下文。

### 6.4 浏览知识库

探索知识库 → 进入某库 → 分类/搜索 → 阅读或提问。

### 6.5 历史与收藏沉淀

历史继续对话 / 删除；收藏文档与回答；统计页再次提问；个人中心调整偏好后登出。

### 6.6 无答案处理

提问无命中 → 空态建议 → 换问法 / 切全部库 / 联系业务对接人。
